# 🏥 Hospital Emergency Room Data Analysis

## 📌 Project Overview

This project focuses on analyzing **Hospital Emergency Room (ER) data** to understand patient flow, waiting time, admission patterns, demographics, and overall emergency room performance.

The data was cleaned and transformed using **Power Query**, analyzed using **Excel and DAX calculations**, and presented through an interactive **dashboard**.

The main goal of this project is to convert raw hospital emergency room data into meaningful insights that can help understand ER operations and patient trends.

---

## 🎯 Project Objectives

* Analyze the number of patients visiting the emergency room.
* Understand patient admission and non-admission patterns.
* Analyze patient demographics.
* Identify waiting-time patterns.
* Analyze patient satisfaction.
* Understand patient visits by age group and gender.
* Identify busy periods and patient trends.
* Create an interactive dashboard for better decision-making.

## 🧹 Data Cleaning

Power Query was used to prepare the raw data for analysis.

The major data-cleaning steps included:

* Removing unnecessary data.
* Handling missing/null values.
* Checking and correcting data types.
* Renaming columns where required.
* Removing duplicate records.
* Standardizing data values.
* Creating useful calculated columns.
* Preparing the cleaned dataset for analysis.

## 📊 Data Analysis

The project analyzes different aspects of emergency room operations, including:

### Patient Analysis

* Total number of patients.
* Patients by gender.
* Patients by age group.

### Admission Analysis

* Admitted patients.

* Admission percentage.

### Waiting Time Analysis

* Average waiting time.
* Waiting-time patterns.
* Waiting time by different patient categories.

### Satisfaction Analysis
